# queueify documentation

The documentation site for [queueify](https://github.com/conditionull/queueify), Live at
[queueify-docs.vercel.app](https://queueify-docs.vercel.app).

Built with [Docus](https://docus.dev) (Nuxt 4 + Nuxt Content + Nuxt UI 4). The bot itself lives
in its own repo: [conditionull/queueify](https://github.com/conditionull/queueify).

Run locally:

```sh
npm install
npm run dev        # http://localhost:3100
```

## Contributing

Contributions to the docs site are welcome: a typo, a page that could be clearer, a missing step, etc. Fork this repo and open a pull request. Every
page is a markdown file under `content/`, and each one has an "Edit this page" link at the
bottom that takes you straight to it.

Bugs and ideas for the bot itself go to the
[bot's repo](https://github.com/conditionull/queueify/issues)
