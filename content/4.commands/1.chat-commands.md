The dashboard has a searchable **Chat commands** card with the same list, showing who can run
each one and any aliases you have set.

::note
Every command name here is the default. All of them can be renamed or given extra aliases in
**Admin Panel → Commands**.
::

## Everyone

| Command | Description |
| --- | --- |
| `!q <spotify_url>` | Queue a Spotify track. Defaults: `360s` maximum song length, `60s` queue cooldown |
| `!q` | Show up to 10 queued songs |
| `!active` / `!np` | Show the song playing right now |
| `!duration` | Show the maximum length a queued song may be |

## Mods only

### The queue

| Command | Description |
| --- | --- |
| `!skip` | Skip to the next Spotify track (needs Premium) |
| `!qon` / `!qoff` | Open or close the queue |
| `!chaton` / `!chatoff` | Allow or stop chat queueing |
| `!rewardon` / `!rewardoff` | Enable or disable the channel point reward |

### Limits

| Command | Description |
| --- | --- |
| `!delay` | Show the queue cooldown |
| `!delay <seconds>` | Change the queue cooldown |
| `!duration <seconds>` | Change the maximum length a song may be |
| `!repeatdelay` | Show the same-user same-song block window |
| `!repeatdelay <seconds>` | Change that window |
| `!explicit on` / `!explicit off` | Allow or prevent explicit songs |

### Blocking

| Command | Description |
| --- | --- |
| `!deny <username>` | Block a user from queueing |
| `!allow <username>` | Unblock a user |
| `!blockartist <artist_name>` | Block an artist, including where they are a featured artist |
| `!unblockartist <artist_name>` | Unblock an artist |
| `!blocksong <spotify_url>` | Block one song |
| `!unblocksong <spotify_url>` | Unblock one song |

### The widget

| Command | Who | Description |
| --- | --- | --- |
| `!theme <name>` | Mods | Switch widget theme, e.g. `!theme swag` |
| `!topright set` / `!tr set` | Mods | Save the widget's position as the first preset |
| `!topright` / `!tr` | Mods and whitelisted viewers | Move the widget to that preset |
| `!bottomcenter set` / `!bc set` | Mods | Save the second preset |
| `!bottomcenter` / `!bc` | Mods and whitelisted viewers | Move the widget to that preset |

::tip{to="/obs/moving-the-widget"}
The position commands need the OBS WebSocket connection, and each theme keeps its own pair.
::

## Details

::collapsible{name="how the queue behaves"}
Each widget theme has its own `!bc` and `!tr` position, so set them per theme if you use the
positional commands.

Pending queued songs, the ones `!q` lists, are reconciled against Spotify's real queue. If the
streamer has the same song in their own generated queue, your request is not removed from the
list when that copy ends.

The queue's open or closed state, the deny list, the cooldown, maximum song length, and repeat
delay all survive a restart.
::
