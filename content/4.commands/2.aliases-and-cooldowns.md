**Admin Panel → Commands** lists every command with a reset to its original name. Changes apply
while the bot runs.

## Renaming

Rename a command or give it extra aliases, for example `!song` alongside `!np`. Both the new
name and the alias work from then on.

Stored in
[`config/aliases.json`](https://github.com/conditionull/queueify/blob/main/config/aliases.json)
if you would rather edit a file. A missing or half-written file falls back to the built-in
names.

## Cooldowns

Each command carries two, both `0` by default except `!np`:

::field-group
  ::field{name="Global" type="seconds"}
  One cooldown for the whole chat. Nobody can run the command again until it is up.
  ::

  ::field{name="Per user" type="seconds"}
  Each viewer waits out their own.
  ::
::

::cooldown-diagram
::

::note
Mods are never held up by either.
::

The queue cooldown is separate. It is how long a viewer waits between **song requests**, and it
is in **Settings**, or `!delay`.
