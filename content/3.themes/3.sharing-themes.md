title: Sharing themes
description: Export a theme to a file, import one somebody sent you.
navigation:
  icon: i-lucide-share-2
---

A theme is a folder under `widget/themes/`. The editor exports and imports one as a single file.

- **Export** writes the theme to a file you can send to anyone else running Queueify
- **Import** brings one in as a **new** theme, so nothing you already have is overwritten

Both are in the theme editor.

::note
An imported theme arrives with its own `!tr` / `!bc` positions unset, because a saved position
is a rectangle measured against a particular source size. Frame it once on your own setup.
::

::tip{to="/obs/moving-the-widget#when-a-saved-position-stops-working"}
Why a position is stored as a rectangle rather than a scale.
::
