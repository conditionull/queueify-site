Map an OBS scene to a theme and Queueify switches to it when OBS cuts to that scene. A slim
strip for gameplay, a larger panel for talking to chat, without typing `!theme` on every
transition.

::scene-themes-diagram
::

::steps{level="3"}

### Connect OBS first

The scene list comes from OBS, so the **OBS** step has to be connected.

::tip{to="/obs/moving-the-widget"}
Setting up the OBS WebSocket connection.
::

### Map a scene to a theme

Open **Widget themes** on the dashboard, and under **A theme per OBS scene** pick a theme beside
any scene.

### Leave the rest alone

Scenes left on **Leave as-is** change nothing, so you can fill this in one scene at a time.

::

## How it interacts with `!theme`

`!theme` takes priority for as long as you stay on the scene you typed it on. The next switch to
a mapped scene overrides it.

::warning
A scene switch reloads the widget, so the first painted frame is what viewers see. If a theme
looks wrong for a moment on transition, that is the frame to check.
::
