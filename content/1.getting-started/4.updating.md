```sh
git pull
npm install
npm start
```

Your Spotify connection, queue settings, blacklist, widget presets, themes, and `.env` are kept
as they are. queueify checks your saved Twitch login and reward on startup, and opens the
dashboard if either needs redoing.

## What changes on the first run

::steps{level="3"}

### Node 20 is the minimum

On anything older queueify stops with a one-line message instead of a stack trace. Update Node
and start it again.

### Your OBS browser source is resized once

To the size the active theme is designed at, with the scene item scaled to match. The widget
stays the same size on stream - it renders at the right number of pixels instead of being
stretched or squashed. Saved `!tr` / `!bc` presets are adjusted at the same time, so they still
land where you set them.

### `config/settings.js` is created if missing

The old `config/settings.example.js` is gone, so there is nothing to copy or rename.

::
