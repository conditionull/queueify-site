::note
**New to this?** The lines in grey boxes below are typed into a terminal, not into a file. A
terminal is the window where you type commands and press :kbd{value="Enter"} to run them.

- **Windows**: press :kbd{value="Win"}, type `powershell`, and open **Windows PowerShell**
  (**Terminal** works too). Right-clicking a folder in File Explorer and choosing **Open in
  Terminal** starts you off in that folder
- **macOS**: press :kbd{value="Cmd"} + :kbd{value="Space"}, type `terminal`, press
  :kbd{value="Enter"}
- **Linux**: your usual terminal emulator

Type or paste one line at a time and press :kbd{value="Enter"} after each. Nothing here needs
Administrator rights.
::

## Install it

::steps{level="3"}

### Clone the repository

```sh
git clone https://github.com/conditionull/queueify.git
```

`cd queueify` means "go into the queueify folder". Every command after it has to be run from in
there, so keep the same window open.

```sh
cd queueify
```

::tip
**Use `git clone` if you can.** Updating is then `git pull`, and your settings, themes, and
logins stay where they are. Downloading the zip works too, but every update means downloading
it again and moving your files across by hand.
[Git for Windows](https://git-scm.com/download/win) takes a minute to install.
::

### Install the dependencies

```sh
npm install
```

### Start it

```sh
npm start
```

That opens the dashboard at `http://127.0.0.1:3002`. The startup banner prints the link, and
the page stays up for as long as the bot runs.

## What happens on first start

There is no configuration file to fill in. The dashboard writes everything Queueify needs, and
only **Twitch** and **Spotify** are required. The other steps can be skipped and added later.

::tip{to="/getting-started/connect-accounts"}
Connecting Twitch and Spotify.
::

## Keeping it up to date

```sh
git pull
npm install
npm start
```

Run `npm install` even when there are no new dependencies. Your Spotify connection, queue
settings, blacklist, widget presets, themes, and `.env` are kept as they are.
