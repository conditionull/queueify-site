Queueify is a Twitch bot that adds Spotify song requests to your playback queue. Viewers request
a track in chat or redeem a channel point reward, and the song is added to your queue if it
passes the limits you set: cooldown, maximum length, a block on repeats, and an explicit filter.

It also includes:

- an **OBS overlay widget** showing the current song, which you can redesign in a visual editor
- a **dashboard** that handles every account and setting, so there is no config file to edit
- a **stats page** counting every request

Everything runs on your own machine. There is no Queueify server and no account to create.

## Requirements

::field-group
  ::field{name="Node.js 20 or newer" type="required"}
  [Download it here](https://nodejs.org/en/download) - the `.msi` on Windows. Queueify checks
  the version on startup and stops with a message if it is older.
  ::

  ::field{name="Spotify Premium" type="required"}
  Adding tracks to the playback queue is a Premium-only part of Spotify's API. Without it
  nothing can be queued.
  ::

  ::field{name="A Twitch account" type="required"}
  The account you approve is the account the bot chats as. It must be your broadcaster account
  or a moderator on your channel, or channel point redemptions will not work.
  ::

  ::field{name="OBS Studio" type="for the widget"}
  [OBS Studio](https://obsproject.com/download) and StreamElements OBS (SE.Live / OBS.Live) are
  tested. Streamlabs and other forks are untested.
  ::
::

## Optional

- **Channel point rewards** - Twitch only allows reward buttons on Affiliate and Partner
  channels. Without one, viewers request songs with `!q`. You can add the reward later
- **Spotify Canvas videos** - needs one cookie pasted into the dashboard. Without it the widget
  shows album art
- **The OBS WebSocket connection** - needed for `!tr` and `!bc`, and for a theme that follows
  your OBS scene
