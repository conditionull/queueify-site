`http://127.0.0.1:3002/admin.html` is where you change settings, rename commands, and reword
what Queueify says in chat.

![The admin panel on the Settings tab](/img/admin-panel.png){.rounded-xl .border .border-default}

## Settings

Cooldown, repeat block, maximum song length, whether chat and channel point requests are on,
explicit tracks, whether the queue is open, and who can move the widget. The same settings the
chat commands change, applied immediately.

The **Whitelist** here is what lets a viewer who is not a mod run `!tr` and `!bc`.

## Commands

Rename any command or give it extra aliases, with a reset to the original. Each command also
carries a global and a per-user cooldown.

::tip{to="/commands/aliases-and-cooldowns"}
How the two cooldowns differ.
::

## Chat messages

Every line Queueify says, grouped and searchable, with a reset to the original wording beside
each one.

Messages use placeholders like `{{username}}`, `{{artist}}` or `{{count}}` for the parts that
change. The panel shows which ones a message has to keep and **refuses a change that drops
one**.

## Where it is stored

Everything is saved to plain files in the project folder:

| File | What it holds |
| --- | --- |
| `queue-settings.json` | Cooldown, maximum length, repeat delay, widget positions |
| `config/aliases.json` | Command names and aliases |
| `config/messages.json` | Every line Queueify says |
| `config/settings.js` | Defaults, created for you if missing |

Editing them by hand still works, and the same reload applies. A missing or half-written file
falls back to the built-in values.
