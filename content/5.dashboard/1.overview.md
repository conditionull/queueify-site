`npm start` opens `http://127.0.0.1:3002` and keeps it running for as long as the bot runs.
Accounts, settings, commands, chat messages, and themes are all set there, so there is no
configuration file to edit.

![The dashboard](/img/dashboard.png)

| Page | What is on it |
| --- | --- |
| `/` | The setup steps: Twitch, Spotify, channel points, OBS, and Canvas videos |
| `/` → Widget themes | Pick the active theme, map a theme to an OBS scene, open the editor |
| `/` → Chat commands | Every command, who can run it, and its aliases |
| `/` → What's new | The changelog for the version you are running |
| `/admin.html` | Settings, commands, and every line Queueify says in chat |
| `/stats.html` | Every request, counted |
| `/editor.html` | The visual theme editor |

Anything in the docs that says "set X" is one of these panels, and none of them need the bot
stopped and started again.

::warning
The dashboard is **loopback-only**: it binds to `127.0.0.1` and nothing else. It serves your
tokens and settings, so it is never exposed to your network.
::

## No restarts

Credentials, settings, aliases, messages, and themes are re-read while the bot runs. Anything
you change on the dashboard applies on the next command.

::tip{to="/reference/ports-and-env"}
Ports are the exception: the dashboard is served on one, so it cannot change them.
::
